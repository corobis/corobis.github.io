familychat

familychat is a personal reminder tool. It reads the open tasks assigned to its single user in Google Tasks and shows them once a day as a reminder in a terminal on that user's own computer.

What it does

  • Reads tasks assigned to the signed-in user, including tasks assigned in a Google Chat Space.
  • Builds a short daily list of open tasks, marking overdue ones where a due date exists.
  • Displays that list locally and waits for the user to acknowledge it.

It is read only. It never creates, edits, or completes tasks. It has one user and is not offered to anyone else.
