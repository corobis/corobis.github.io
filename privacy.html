familychat privacy notice

Last updated 25 November 2026. Back to familychat.

familychat no longer accesses, stores or shares any Google user data. It stopped reading Google Tasks on 24 November 2026. Its OAuth access has been revoked, its stored refresh token and client credentials have been deleted, and its Google Cloud project has been shut down. The state files it kept on the user's own computer were pruned of every Google Tasks identifier on its first run after that date. No copy of any Google user data remains.
