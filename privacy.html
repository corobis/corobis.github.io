familychat privacy policy

Last updated 12 September 2026. Back to familychat.

Who this covers

familychat is a personal tool with a single user, the person who installed it and signed in. There are no other users and no accounts.

What Google user data familychat accesses

familychat requests one scope, https://www.googleapis.com/auth/tasks.readonly. With it the application reads the signed-in user's Google Tasks: task titles, notes, due dates, completion status, and the identifier of the Google Chat Space a task was assigned in. It requests no other scope and can read no other Google data.

How that data is used

Task data is used only to build a daily reminder list shown to the signed-in user on their own computer. It is used for no other purpose.

How that data is stored

Task data is held in memory while the reminder is built. The reminder itself is then written to a file on the signed-in user's own computer, in a directory readable only by that user's own operating system account. That file holds the open task titles and, where a task has one, that task's due date. It holds no task notes, no links, and no Google Chat Space identifiers. It is overwritten on every run, so it carries the current reminder and no history. The OAuth refresh token is stored in a separate file in the application's configuration directory, readable only by the same operating system account. Nothing is written to a database and nothing is uploaded anywhere. There is no server and no hosted component.

How that data is shared

familychat shares Google user data with no one. It sends no data to any third party, transfers none to any other service, and uses none for advertising, profiling, credit assessment, or training machine learning models. No human other than the signed-in user reads it.

Limited Use

familychat's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Nothing is retained beyond the reminder file described above, which stays on the user's own computer and is replaced by the next run. The user can revoke familychat's access at any time at myaccount.google.com/permissions, and can delete every copy of their Google user data, the reminder file and the stored token alike, by removing the application's state directory and its configuration directory (on Linux, ~/.local/state/familychat and ~/.config/familychat). That leaves no copy of any Google user data.
