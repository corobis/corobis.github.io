familychat privacy policy

Last updated 11 September 2026. Back to familychat.

Who this covers

familychat is a personal tool with a single user, the person who installed it and signed in. There are no other users and no accounts.

What Google user data familychat accesses

familychat requests one scope, https://www.googleapis.com/auth/tasks.readonly. With it the application reads the signed-in user's Google Tasks: task titles, notes, due dates, completion status, and the identifier of the Google Chat Space a task was assigned in. It requests no other scope and can read no other Google data.

How that data is used

Task data is used only to build a daily reminder list shown to the signed-in user on their own computer. It is used for no other purpose.

How that data is stored

Task data is held in memory while the reminder is built and displayed, and is not written to a database or uploaded anywhere. The OAuth refresh token is stored in a file readable only by the user's own operating system account, on that user's computer. There is no server and no hosted component.

How that data is shared

familychat shares Google user data with no one. It sends no data to any third party, transfers none to any other service, and uses none for advertising, profiling, credit assessment, or training machine learning models. No human other than the signed-in user reads it.

Limited Use

familychat's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Nothing is retained beyond the run that displays a reminder. The user can revoke familychat's access at any time at myaccount.google.com/permissions and delete the stored token by removing the application's configuration directory. That leaves no copy of any Google user data.
